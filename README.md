# e-commerce-sql-analysis
E-commerce SQL Data Analysis

Hi everyone, and welcome to my GitHub project! 👋

This is my first project as an aspiring Data Analyst. I use SQL and PostgreSQL to analyze e-commerce data, explore sales trends, understand customer behavior, and evaluate product performance.

The project focuses on answering 10 business questions, including revenue growth, top-selling products, customer retention, and customer value.

Tools: SQL, PostgreSQL, DBeaver, GitHub.

My goal is to turn raw data into meaningful business insights and actionable recommendations while developing my data analytics skills.

Thanks for visiting my project! 🚀
